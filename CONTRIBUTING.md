# Contributing to ORS

Thank you for your interest in Open Recording Software.

## Getting started

1. Read the [project plan](screen-recorder-plan.md) for architecture and phase roadmap.
2. Set up your build environment (see `docs/building.md`).
3. Open an issue before large changes.

## Pull requests

- Keep PRs focused on a single phase or feature.
- Follow existing code style and module boundaries (`ui` → `core` → `capture` / `audio` / `encode` / `mux`).
- Update `CHANGELOG.md` under `[Unreleased]` when appropriate.

## Branches

- `main` — stable
- `feature/<name>` — new work
